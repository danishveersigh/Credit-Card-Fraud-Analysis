# Credit Card Fraud Analysis
Data Science internship projects at Skillairo.
- Minor project: Exploratory data analysis (minor_eda.ipynb)
- Major project: Fraud detection with Logistic Regression and Random Forest (major_fraud_detection.ipynb)
Dataset: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
(Download creditcard.csv and place it in the same folder as the notebooks.)
Tools: Python, Pandas, Matplotlib, Scikit-learn, Imbalanced-learn
